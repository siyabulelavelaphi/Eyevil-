EYEVIL STORE
============

Free static storefront starter for GitHub Pages.

Files:
- index.html
- style.css
- script.js
- assets/eyevil-hero.png

To publish:
1. Create a GitHub account.
2. Create a new PUBLIC repository (for example: eyevil-store).
3. Upload all files and the assets folder.
4. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
5. GitHub will give you a https://YOURUSERNAME.github.io/eyevil-store/ address.

The cart works in the browser using localStorage.
Checkout is intentionally a demo until you connect a payment provider.
